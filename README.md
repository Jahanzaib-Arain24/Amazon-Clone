## 📖 Overview

The **Amazon Clone (PRO)** is a meticulously crafted replica of one of the world's most iconic e-commerce interfaces. It was built to demonstrate advanced frontend layout techniques, CSS architecture, and the power of pure Vanilla CSS for creating complex, enterprise-level designs without heavy frameworks.

**What makes it unique?**
- **Pixel-Perfect Accuracy**: Every component from the navbar to the footer mimics the real Amazon experience.
- **A to Z Responsiveness**: Custom-tailored media queries for 360px, 390px, 768px, 1024px, and 1366px screens.
- **Micro-Animations**: Smooth hover effects, scaling icons, and entry animations for a premium feel.
- **No Frameworks**: Pure HTML and CSS code, optimized for lightning-fast loading speeds.

**Live Site**: <a href="https://jahanzaib-amazon.netlify.app/" target="_blank">Amazon Clone Live Demo</a>

## ✨ Features

- 🎨 **Responsive Design** - Optimized for 360px (Mobile) up to 1920px (Desktop).
- 🔍 **Dynamic Navbar** - Authentic Amazon search bar, location picker, and interactive account/cart sections.
- 🖼️ **Hero Section** - High-quality hero banners with a localized "India/International" message bar.
- 📦 **Product Grids** - Flexbox-powered responsive product cards with hover-scaling effects.
- 📑 **Amazon Categories** - Structured layouts for Fashion, Electronics, Beauty, and more.
- 🔝 **Back to Top** - Functional anchor navigation for smooth scrolling.
- 🔗 **Deep Footer** - Full multi-paneled footer with realistic navigational links and copyright info.

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Edge, Firefox, etc.)
- A code editor like [VS Code](https://code.visualstudio.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/jahanzaibarain/Amazon-Clone.git
   ```

2. **Navigate to project directory**
   ```bash
   cd Amazon-Clone
   ```

3. **Open the project**
   Simply open `index.html` in your browser or use the **Live Server** extension in VS Code.
